# MaxValu-Analyzer

## StoreFlow-Sim 店舗回転率シミュレーター

マックスバリュのレイアウトに基づいた、店舗内客流シミュレーター。

## 目的
- 特売品の位置（マグネットパワー）が、店舗全体の回転率に与える影響を可視化する。
- 通路の狭さによる渋滞ポイントを特定する。

## 機能
- **群衆シミュレーション**: 100人の客が自律的に移動。
- **物理演算**: Pymunkによるリアルな衝突・回避判定。
- **可視化**: Streamlitによるリアルタイム統計グラフ。

## インストール

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
streamlit run app.py
```

ブラウザが自動的に開き、シミュレーションが表示されます。

## 操作方法

### メイン画面
- **▶️ 開始**: シミュレーションを開始・一時停止
- **🔄 リセット**: シミュレーションをリセット

### サイドバー
- **シミュレーション速度**: 1倍速～5倍速で調整可能
- **特売エリア位置**: X座標・Y座標をスライダーで調整

### 表示内容
- **経過時間**: シミュレーション開始からの経過時間
- **現在の店内人数**: 現在店内にいる客の数
- **累計退店数**: これまでに退店した客の総数
- **退店数グラフ**: 時間経過ごとの累計退店数を折れ線グラフで表示

## シミュレーションの動作

### 客の行動フロー
1. **入店**: 画像下部右側から入店（x=0.8, y=0.9付近）
2. **特売エリア**: 特売エリアで5秒間滞在
3. **ランダムな棚1**: 最初の棚で3秒間滞在
4. **ランダムな棚2**: 2番目の棚で3秒間滞在
5. **レジ**: 最も空いているレジに並び、会計（2～5秒）
6. **退店**: 画像下部左側から退店（x=0.2, y=0.9付近）

### 特徴
- 各客は個別の移動速度（0.8倍～1.2倍のランダム）を持つ
- 客同士の衝突判定が有効で、重ならないように回避
- 床面画像の黒いピクセルを壁として認識し、通れないように設定
- 5つのレジは画像下部中央に横並びで配置

## ファイル構成

- `app.py`: メインのStreamlitアプリケーション
- `floor_plan.jpg`: 店舗レイアウトの画像（黒い部分が壁）

- **Pymunk**: 2D物理演算エンジン
